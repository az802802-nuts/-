# 要件定義書：路地珈琲（Roji Coffee）Webサイト制作

作成: Bridge株式会社 プロジェクトディレクター
参照元ブリーフ: `docs/00-brief.md`

---

## 1. サイトのゴール・コンセプト

路地裏にひっそりと佇む個人経営カフェ「路地珈琲」の隠れ家的な雰囲気と、豆選び・焙煎へのこだわりを伝え、
SNSで店を知った初めての人が「行ってみたい」と思い、迷わず来店できる（場所・営業時間がわかる）ようにする、
シンプルな静的Webサイトを制作する。

## 2. ターゲットユーザー像

- **メインターゲット**: SNS（Instagramなど）で偶然お店を見かけ、興味を持った30〜50代の大人。落ち着いた雰囲気の店を好み、初めての来店に少し不安がある層。
- **サブターゲット**: 近隣に住む・勤める人で、仕事帰りや休日に静かに過ごせるカフェを探している人。
- **既存の常連客**: 営業時間の確認やメニューの再確認など、軽い情報チェック用途でも利用。

いずれも「賑やかさ」より「落ち着き」を求めている点が共通。派手な演出より、安心感と信頼感を優先する。

## 3. サイトマップ

全3ページの小規模構成とする。

| ページ名 | ファイル名 | 目的 |
|---|---|---|
| トップページ | `index.html` | 店の世界観（隠れ家感・静けさ）を第一印象で伝え、メニュー・こだわり/アクセスへ誘導する入り口 |
| メニュー | `menu.html` | コーヒー・軽食・スイーツのラインナップと価格帯の目安を紹介し、来店前の期待値をつくる |
| こだわり・アクセス | `about.html` | 豆の産地・焙煎方針などの世界観の裏付けと、営業時間・所在地などの実用情報を伝え、来店を後押しする |

- 全ページ共通でヘッダー（店名ロゴ／簡易ナビ）とフッター（営業時間・所在地の要約、SNSリンク想定）を設置する。
- ナビゲーションは「トップ／メニュー／こだわり・アクセス」の3項目のみとし、迷わせない設計にする。

## 4. 各ページのコンテンツ要素

### 4.1 トップページ（index.html）
- ファーストビュー：店名「路地珈琲」＋一言コピー（隠れ家感が伝わるキャッチコピー）、雰囲気を示すビジュアル（プレースホルダー可）
- お店紹介文（2〜3文程度）：住宅街の路地裏にある小さな喫茶店であること、静かに過ごせる空間であることを紹介
- 店の魅力ピックアップ（3項目程度、アイコン or 短文カード）：例）「厳選した豆」「静かな時間」「隠れ家の立地」
- メニューページへの誘導（一部メニューの抜粋紹介＋「メニューを見る」ボタン）
- 営業時間・アクセスの要約（詳細ページへの誘導）＋「こだわり・アクセスを見る」ボタン

### 4.2 メニューページ（menu.html）
- ページ導入文（1〜2文：メニューへのこだわりを軽く添える）
- コーヒーセクション：見出し「コーヒー」＋品目リスト（例：ブレンド、ドリップシングルオリジン、カフェラテなど）と価格目安
- 軽食セクション：見出し「軽食」＋品目リスト（例：サンドイッチ、トーストなど）と価格目安
- スイーツセクション：見出し「スイーツ」＋品目リスト（例：本日のケーキ、焼き菓子など）と価格目安
- 補足注記（例：仕入れ状況により内容が変わる場合がある旨）

### 4.3 こだわり・アクセスページ（about.html）
- こだわりセクション：見出し「豆へのこだわり」＋産地選定・焙煎方針についての紹介文
- 空間・時間へのこだわりセクション：見出し「静かな時間」＋店内の雰囲気・コンセプトの補足紹介
- 営業時間セクション：見出し「営業時間」＋曜日別の営業時間・定休日
- アクセスセクション：見出し「アクセス」＋住所（架空）、最寄駅からの行き方の説明、地図（プレースホルダーでよい）
- お問い合わせ・SNSリンク（任意、あれば末尾に）

## 5. トーン&マナー

- **文体**: 丁寧語をベースにしつつ、堅苦しくなく落ち着いた語り口。過度な絵文字・カジュアルすぎる表現は避ける。
- **雰囲気**: 「隠れ家」「静けさ」「大人の時間」を軸に、余白を活かした静かな印象。賑やかさや過剰な訴求（セール感・煽り文句）は使わない。
- **ビジュアルの方向性**: ブラウン・ベージュ・深緑など落ち着いた色調を想定（実写画像がないため、CSSグラデーションやイラスト調SVG等のプレースホルダーで雰囲気を代替する）。
- **言葉選び**: 「こだわり」「静かに」「路地裏」「一杯」など、ゆったりとした時間を連想させる語彙を意識する。

## 6. 成功指標

- 初めてサイトを訪れた人が、店の雰囲気（隠れ家感・落ち着き）を第一印象で感じ取れること。
- 営業時間・アクセス（場所）に関する情報に、トップページから2クリック以内でたどり着けること。
- メニュー内容（コーヒー・軽食・スイーツ）が一覧できる状態になっていること。
- スマートフォンでの閲覧時にレイアウト崩れがなく、文字・ボタンが問題なく読める／押せること。
- SNS経由の流入を想定し、どのページから見ても店名・雰囲気・アクセス情報が短時間で把握できること。
