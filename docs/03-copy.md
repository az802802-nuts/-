### お店紹介文
```
路地珈琲は、住宅街の細い路地を少し入った先にある、小さな喫茶店です。
表通りの喧騒から離れたこの場所では、時間の流れが少しだけゆっくりと感じられます。
一杯の珈琲とともに、誰にも急かされない静かなひとときをお過ごしください。
```

### 店の魅力ピックアップ（3項目）

**1. 厳選した豆**
```
産地と焙煎士の顔が見える豆だけを、少量ずつ仕入れています。
```

**2. 静かな時間**
```
BGMは控えめに、会話がなくても心地よくいられる空間です。
```

**3. 隠れ家の立地**
```
表通りからは見えない路地の奥。知る人だけがたどり着ける場所です。
```

## 3. こだわり・アクセスページ（about.html）

### 豆へのこだわり
```
路地珈琲でお出しする珈琲豆は、生産者や焙煎士の顔が見えるものだけを、少量ずつ選んで仕入れています。
産地ごとの個性を活かすため、深煎り・浅煎りと焙煎の度合いを豆に合わせて変え、
一杯ごとに、その土地の風土や作り手の手間までをカップに閉じ込めるつもりで淹れています。
派手さよりも、静かに舌に残る余韻を大切にした一杯です。
```

### 静かな時間
```
路地珈琲では、大きな音楽をかけず、席と席の間にもゆとりを持たせています。
本を読む方、ノートを広げる方、ただぼんやりと窓の外を眺める方。
どんな過ごし方をしていただいても構いません。
誰にも急かされることのない、大人のための静かな時間をご用意しています。
```
