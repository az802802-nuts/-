# デザインコンセプト：路地珈琲（Roji Coffee）Webサイト

作成: Bridge株式会社 ビジュアルデザイナー
参照元: `docs/01-requirements.md`（要件定義書）

---

## 1. 全体の世界観・雰囲気（コンセプトフレーズ）

> **「路地の奥で、時間を一杯分だけ緩める。」**

住宅街の路地裏にひっそりと存在する隠れ家カフェという設定を、Web上でも「見つけた人だけが辿り着ける静けさ」として表現する。派手な訴求や賑やかさは避け、余白を多くとった構成で「静かに過ごせる場所である」ことを視覚的に先に伝え、文章はその余韻を補足する役割に留める。ボタンやリンクの動きも急かさず、ホバー時の色変化やフェードもゆっくりとした速度感（0.3〜0.5秒程度を想定）で、「せかせかしない」体験そのものをデザインの一部とする。

## 2. カラーパレット

落ち着いたブラウン・ベージュ・深緑を基調とし、コントラストは十分に確保しつつも彩度を抑えて「大人の隠れ家」感を演出する。

| 役割 | カラー名（イメージ） | Hex | 用途 |
|---|---|---|---|
| メインカラー | 焙煎ブラウン | `#5B4034` | ロゴ、見出し装飾、主要ボタン背景 |
| サブカラー | 深緑（モスグリーン） | `#3E4A3D` | セクション区切り、アイコン、フッター背景 |
| アクセントカラー | 温かなキャメル | `#B08652` | ボタンのホバー色、リンクの下線、価格表示などの強調点 |
| 背景カラー（ベース） | ミルクベージュ | `#F5EFE6` | ページ全体の背景 |
| 背景カラー（面替え用） | くすみベージュ | `#EAE0D1` | セクションの背景色を交互に切り替える際の濃淡差分 |
| テキストカラー（本文） | 墨黒に近いブラウン | `#3A2E27` | 本文・見出しの基本文字色 |
| テキストカラー（補足） | グレーブラウン | `#8A7B6E` | 補足注記、キャプション、日付などの弱い情報 |
| 反転テキスト | クリームホワイト | `#FBF7F0` | 濃色背景（フッター、深緑背景など）の上の文字色 |

- 全体の彩度は低め（くすみ色）に統一し、純白（`#FFFFFF`）や真っ黒（`#000000`）は使用しない。地の色がやや黄み・茶みを帯びていることで「灯りの温かさ」を演出する。
- アクセントカラーは多用せず、CTAボタンや価格・重要語句など「視線を止めたい箇所」のみに絞って使用する。

## 3. タイポグラフィ方針

### 見出し用フォント
- 方向性：明朝体・serif系で、やや細身〜中太のウェイトを基本とする。角ばった印象を避け、縦組みの余白が美しい書体を選定する。
- 想定する日本語Webフォント：**「Noto Serif JP」**（Google Fonts）を第一候補とする。店名ロゴ相当の箇所（「路地珈琲」表記）は、可能であればさらに柔らかい雰囲気の明朝系（例：「クイックサンド」的な丸みではなく、あくまで和の明朝の趣を持つもの）でも良いが、実装コストを鑑み Noto Serif JP のウェイト差（例：400と600〜700）で見出しと本文のメリハリを作る運用を基本とする。
- 見出しの文字間（letter-spacing）はやや広め（0.05em〜0.1em程度）に取り、静けさ・余裕を感じさせる。

### 本文用フォント
- 方向性：可読性を優先したゴシック体（sans-serif）を基本とし、見出しの明朝体と組み合わせることで「和の落ち着き」と「読みやすさ」を両立する。
- 想定する日本語Webフォント：**「Noto Sans JP」**（Google Fonts）を第一候補とする。ウェイトは本文400、強調部分500〜700を使い分ける。
- 行間（line-height）は1.8〜2.0程度とゆったり取り、余白を活かした「静かな時間」の読書体験を作る。
- 本文の文字サイズは16px（1rem）を基準とし、スマホでも縮小しすぎない。

### 全体方針
- 見出し＝明朝（Noto Serif JP）、本文・ナビ・ボタン＝ゴシック（Noto Sans JP）という組み合わせを全ページで統一する。
- 欧文が混じる場合（例：ロゴ英語表記 "Roji Coffee" など）は、和文フォントに付随する欧文グリフをそのまま使用し、書体を混在させすぎない。

## 4. レイアウト／ワイヤーフレーム

3ページ共通で、ヘッダー（店名ロゴ＋簡易ナビ3項目：トップ／メニュー／こだわり・アクセス）を最上部、フッター（営業時間・所在地の要約、SNSリンク想定）を最下部に固定的に配置する。ヘッダーは背景色をベースカラー（ミルクベージュ）または半透明の白味がかった背景とし、スクロールしても控えめに追従する形式（sticky）を想定するが、主張しすぎないよう影は薄く、境界線も淡色の1px程度に留める。

### 4.1 トップページ（index.html）— 上から順に

1. **ヘッダー**（共通）
2. **ファーストビュー（メインビジュアル）**：画面高さの70〜100vh程度を使い、背景はグラデーション（ブラウン系〜深緑系の斜めグラデーション、または縦グラデーション）のプレースホルダー。中央〜やや左寄せに店名「路地珈琲」（明朝・大きめ）と、隠れ家感を伝える一言コピー（例：「路地の先に、灯りがひとつ。」といった短いキャッチコピー）を配置。下部にごく控えめなスクロール誘導（矢印や「Scroll」の小さな表記）を置いてもよい。
3. **お店紹介文セクション**：背景はベースカラー、中央寄せまたは左寄せの2〜3文程度の紹介文。文章量が少ないため、左右に大きめの余白（コンテンツ幅を60〜70%程度に絞る）を取り、「読ませる」より「感じさせる」レイアウトにする。
4. **店の魅力ピックアップセクション**：見出し（例：「路地珈琲がお届けするもの」）の下に、3項目のカードを横並び（PCでは3カラム）で配置。各カードはアイコン（線画調のシンプルなSVGアイコンを想定：豆・時計・地図ピンなど）＋短い見出し（「厳選した豆」等）＋一言説明文の構成。カード背景は薄いベージュ、境界は淡い線または微小な影のみで、装飾を抑える。
5. **メニュー誘導セクション**：背景色を変える（くすみベージュ系や薄い深緑系）ことで前後のセクションと区切りをつける。見出し（「メニュー」等）の下に、代表メニュー2〜3品を簡易カードまたはリストで抜粋紹介（品名＋価格目安程度の軽い情報量）し、その下に「メニューを見る」ボタン（アクセントカラーでの控えめな縁取りボタン、または深いブラウン地に反転テキストのボタン）を中央配置。
6. **営業時間・アクセス要約セクション**：見出し（「営業時間・アクセス」等）の下に、営業時間の概要（例：曜日と時間帯を1〜2行で）と所在地の簡易な説明を短くまとめ、「こだわり・アクセスを見る」ボタンを配置。地図画像は使わず、テキスト中心の簡潔な要約に留める。
7. **フッター**（共通）

### 4.2 メニューページ（menu.html）— 上から順に

1. **ヘッダー**（共通）
2. **ページタイトル・導入文セクション**：シンプルな見出し「MENU（メニュー）」＋メニューへのこだわりを添えた1〜2文の導入文。背景はベースカラーで、余白を広めに取る。
3. **コーヒーセクション**：見出し「コーヒー」（明朝＋アクセントカラーの下線または脇に小さな装飾線）＋品目リスト。各品目は「品名（左）－価格（右）」の1行形式を基本とし、品目間に薄い罫線または余白で区切りをつける。品数が多い場合は2カラム（PCのみ）にしてもよい。
4. **軽食セクション**：見出し「軽食」＋コーヒーセクションと同様のリスト形式。背景色を軽く変えて（例：くすみベージュ）前セクションとの区切りを明確にする。
5. **スイーツセクション**：見出し「スイーツ」＋同様のリスト形式。背景色は元のベースカラーに戻す、といった形で背景の濃淡を交互に使い、セクションの切れ目を分かりやすくする。
6. **補足注記**：ページ最下部、本文より小さめの文字サイズ・補足テキストカラー（グレーブラウン）で「仕入れ状況により内容が変わる場合がございます」等の一文を配置。
7. **フッター**（共通）

### 4.3 こだわり・アクセスページ（about.html）— 上から順に

1. **ヘッダー**（共通）
2. **ページタイトルセクション**：見出し「こだわり・アクセス」。トップページのファーストビューよりは控えめな高さ（30〜40vh程度）で、背景にグラデーションのプレースホルダーを薄めに敷いてもよい。
3. **豆へのこだわりセクション**：見出し「豆へのこだわり」＋産地選定・焙煎方針の紹介文。テキストとプレースホルダービジュアル（後述）を左右2カラム（PC）／縦積み（スマホ）で配置し、単調な文章の羅列にならないようにする。
4. **静かな時間セクション**：見出し「静かな時間」＋店内の雰囲気・コンセプトの補足紹介文。前セクションと左右の配置（画像とテキストの左右）を反転させ、リズムをつける。
5. **営業時間セクション**：見出し「営業時間」＋曜日別の営業時間・定休日を表形式またはリスト形式（曜日：時間の対）で明示。定休日は視認しやすいよう強調（アクセントカラーの文字色など）。
6. **アクセスセクション**：見出し「アクセス」＋住所（架空）、最寄駅からの行き方の説明文、地図プレースホルダー（後述）を配置。テキストと地図プレースホルダーは縦並び、または左右並び（PC）とする。
7. **お問い合わせ・SNSリンク（任意）**：ページ最下部、フッター手前に控えめに配置。アイコンのみのシンプルなリンク列とする。
8. **フッター**（共通）

## 5. 写真・イラストの方向性（実写なし前提）

実写画像を一切使用しない前提のため、以下の手法で「雰囲気」を代替する。

- **メインビジュアル（ファーストビュー）**：ブラウン〜深緑〜ベージュを基調とした斜め45度または縦方向のCSSグラデーションを背景に敷く。単一のグラデーションでは単調になるため、うっすらとした光の粒子・湯気のような揺らぎを表現する半透明の円形ぼかし（radial-gradientの重ね合わせ）を1〜2箇所加え、「灯り」「湯気」を暗示する。
- **アイコン類（魅力ピックアップ、SNSリンクなど）**：線画（ストローク）ベースのシンプルなSVGアイコンを使用する。塗りつぶしを避け、線の太さを統一し、角を丸めた優しい印象のアイコンセットとする（豆のモチーフ、湯気の立つカップ、地図ピン、時計など）。色はメインカラーまたは深緑を基本とし、単色使いに統一する。
- **セクション間の区切り装飾**：コーヒーの湯気や豆をモチーフにした、ごく控えめな線画イラスト（SVG）をセクション見出しの脇や区切り線代わりに小さく添えるのは可とするが、多用しない。あくまで主役はテキストと余白。
- **地図プレースホルダー**：実際の地図APIやスクリーンショットを使わず、簡易的な線画調の地図イラスト（道と目印のピンのみのシンプルな構成）、またはベージュ系の背景に「MAP」の文字とピンアイコンを中央配置したプレースホルダーボックスで代替する。将来的に実際の地図に差し替えやすいよう、専用のブロックとして独立させる。
- **コーヒー豆・カップのモチーフ画像が欲しい箇所（こだわりセクションなど）**：写真の代わりに、シンプルな幾何学的シルエット（カップの断面、豆の粒を並べたパターンなど）をSVGまたはCSSで表現し、背景色との明暗差だけで形を見せるミニマルな表現とする。

## 6. レスポンシブ対応の方針

- **ブレークポイント**：スマホ（〜767px程度）／タブレット（768px〜1023px程度）／PC（1024px〜）の3段階を基本とし、特にスマホ表示を最優先で崩れなく設計する（要件のメインターゲットがSNS経由のスマホ閲覧を想定しているため）。
- **ナビゲーション**：スマホではヘッダーの3項目ナビをハンバーガーメニュー化せず、そのまま横並びの3項目（トップ／メニュー／こだわり・アクセス）を小さめの文字サイズで収める方針を基本とする。項目数が3つと少ないため、開閉式メニューにせず「常に見えている」状態を保ち、迷わせない設計にする。
- **カラム構成**：PCで横並び（3カラムの魅力ピックアップ、2カラムのこだわり紹介など）にしているセクションは、スマホでは全て縦1カラムに積み替える。画像（プレースホルダー）とテキストの左右配置も、スマホでは「画像→テキスト」の縦順に統一する。
- **文字サイズ・タップ領域**：本文は最小でも15〜16px相当を確保し、縮小しすぎない。ボタンやナビリンクのタップ領域は縦方向44px以上を目安に確保し、指で押しやすくする。
- **余白の調整**：PCでのゆったりとした余白（セクション上下のpaddingなど）は、スマホでは絶対値としては縮小しつつも、要素同士が詰まって見えないよう相対的な余白バランスは維持する（「静けさ」を保つための最低限の余白は削らない）。
- **メインビジュアルの高さ**：スマホではファーストビューの高さをPCの70〜100vhからやや抑え（60〜80vh程度）、コピーとタイトルがファーストビュー内に収まり、スクロールしなくても店名とキャッチコピーが視認できることを優先する。
- **表・リスト形式の情報（メニュー価格、営業時間）**：PCでの2カラム表示等は、スマホでは1カラムの縦リストに変更し、品名と価格の対応が視線移動なく分かるよう「品名の直下または右隣に価格」を保ったまま折り返す。
