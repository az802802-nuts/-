# 案件ブリーフ（架空案件）

- 発注元: ナオヤのBridge株式会社（社内バーチャルオフィス上の架空案件）
- クライアント: 個人経営のカフェ「路地珈琲（Roji Coffee）」（架空）

## クライアント概要
東京都内、住宅街の路地裏にある小さな喫茶店。オーナーが自家焙煎に近い豆選びにこだわり、
静かに過ごせる大人向けの空間を提供している。常連中心だが、最近SNSで少しずつ知られ始め、
初めての人にも店の雰囲気や場所が伝わるWebサイトが欲しいと考えている。

## 要望
- 店の雰囲気（隠れ家感、落ち着き）が伝わるサイトにしてほしい
- メニュー（コーヒー、軽食、スイーツ）を紹介したい
- 営業時間・アクセス・こだわり（豆の産地や焙煎方針など）を伝えたい
- スマートフォンでも見やすくしてほしい
- 予算・納期は限られているため、まずはシンプルな静的サイトで十分

## 制約・前提
- 架空案件のデモのため、実装は素のHTML/CSS/JS（フレームワーク不要）で問題ない
- 画像は実写がないため、プレースホルダー（CSSグラデーションやイラスト調のSVGなど）で代替してよい
