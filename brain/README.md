# Brain販売用｜情報コンテンツ設計一式（直也さん向け）

このフォルダは、直也さんが **Brain（brain-market.com）等で販売する有料コンテンツ** を、
企画 → 執筆 → 販売 → 拡散まで一本道で作れるようにまとめた設計書です。

## なぜこの企画なのか（前提）

このリポジトリには `horoscope_github_pages_site.zip`（LINE風の星座占いミニアプリ／1ファイルHTML＋GitHub Pages公開手順）が入っています。
つまり直也さんは既に **「AIに1ファイルのWebアプリを作らせて、無料で自分のURLとして公開する」** という、
初心者が一番つまずくラインを越えている状態です。

コンテンツ販売で一番売れるのは「1歩先を行く人が、半歩後ろの人に教える」もの。
この既存アセットは、そのまま **商品の実演デモ・特典テンプレ・実績スクショ** の3役を兼ねます。ゼロから作る必要がありません。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `01_商品設計書.md` | 本命企画・ペルソナ・提供価値・価格/紹介料率・収益シミュレーション・別案2つとの比較 |
| `02_本編構成案.md` | 全9章の目次、各章に書くこと・見せるスクショ・文字数目安（合計1.5〜2万字） |
| `03_セールスレター雛形.md` | Brain販売ページの下書き（無料パートの切り方／穴埋め式コピー） |
| `04_ローンチ14日プラン.md` | 制作〜販売の日割り、X投稿テンプレ7本、アフィリエイター向け素材 |
| `05_チェックリストとリスク.md` | 公開前チェック、景表法・特商法・著作権・各規約の注意点 |
| `06_市民セミナー企画案.md` | **案D**：市民向けセミナー運営ノウハウの売れるか判定と設計（枠の6ルート・企画書・売らない売り方） |
| `08_集客導線と誠実設計.md` | **章立てv2**：広報誌・無料→有料導線を核心章に。申請実務は「調べ方」に変換する誠実設計 |
| `07_本命案E_AI講座パッケージ.md` | **案E（本命）**：案A＋案Dの統合。AIで講座資料を作り、公民館の枠で"先生"になる（9,800円＋29,800円） |

## 3行サマリー

- **商品**：『コード0行。AIに"遊べる診断アプリ"を作らせて、今日中に自分のURLで公開する方法』（テンプレ5種＋プロンプト30本つき）
- **価格**：本編 2,980円（先行7日間 1,480円）／紹介料率 40%／第2弾に制作代行キット 9,800円
- **勝ち筋**：無料パートで「読者が実際に1個公開できてしまう」ところまで出す → レビューと紹介（アフィリ）が回る

## 最初にやること（今日）

1. `01_商品設計書.md` を読んで、本命案でいくか別案にするか決める
2. `04_ローンチ14日プラン.md` の Day1 に着手（デモを1本、実際に公開してURLを取る）
3. 実績が無い状態なので、**先に14日で「自分と読者5人の再現データ」を作る**（詳細は04）

> 数字（手数料12%・紹介料率0〜50%）は2026年8月時点の調査ベースです。販売直前に必ず公式で最新を確認してください。
