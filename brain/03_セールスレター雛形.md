## 無料パートの設計（ここが売上を決める）

**無料で読ませる範囲：第0章〜第2章（＝読者が実際に1個公開できるところまで）**

もったいなく感じますが、これが正解です：

- 「本当に自分でもできた」という体験がそのまま **レビューの動機** になる
- 無料部分だけで感謝されるので、**紹介（アフィリ）してくれる人が出る**
- 有料部分は「AIに好きなものを作らせる型・テンプレ5種・拡散・収益化」＝ **繰り返し使える資産** 側なので価値が下がらない

有料の切れ目に置く一文：

> ここまでで、あなたはもう「自分のURLで動くページ」を持っています。
> ここから先は、**それをAIに好きなだけ量産させて、人に見てもらい、お金に変える**パートです。

## セールスレター本文（雛形）

### 冒頭（フック）

```
コードは1行も書いていません。

〈スマホの画面写真〉

これ、AIに指示を出して〈◯〉分でできたものです。
URLはこちら → 〈デモURL〉（スマホでそのまま遊べます）

僕は〈職業/バックグラウンド〉で、プログラミングの勉強をしたことはありません。
それでも、この記事のとおりに進めれば、今日中に同じものが作れます。しかも無料で。
```

### 問題提起（読者の現在地を言語化）

```
・AIで文章は作れるようになった。でも「作品」がない
・毎日投稿しているのに、いいねが数件で止まる
・「何か売りたい」けど、売るものがない
・プログラミングは何度も挫折した

原因はセンスでも努力でもなくて、
「触って遊べるモノ」を持っていないから、だと思っています。
```

### 転換（解決策の提示）

```
文章は流れていきます。でも、遊べるページは"配られます"。

「これ何？」→ URLを送る → 相手が遊ぶ → 「どうやって作ったの？」

この3往復が、フォロワーを"お客さん"に変えます。
やることは3つだけ。
① AIに1つのファイルで作らせる
② GitHubという無料の置き場に置く
③ 出てきたURLを貼る
```

### 証拠（※事実のみ）

```
・僕が作った〈3〉本の作品と、その公開URL
・公開後〈X日〉での反応：〈インプレッション〉/〈保存数〉/〈DM◯件〉
・未経験のモニター〈5〉人に手順を試してもらった結果：
  〈全員が◯分以内に公開まで到達／その時のスクショと感想〉
```

> ⚠️ 収益額の記載は慎重に。書くなら「これは僕の場合であり、同じ結果を保証するものではありません」を必ず併記。
> 「必ず稼げる」「誰でも月◯万」は書かない（→ `05_チェックリストとリスク.md`）。
