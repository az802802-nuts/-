## 第2章｜まず1つ公開する（2,500字・**前半まで無料／後半から有料**）

ここが最速の成功体験。**AIを使う前に、用意したHTMLをコピペして公開まで済ませる。**

1. 新規リポジトリを作る（Public／名前の付け方）
2. `index.html` をアップロード（ドラッグ＆ドロップ／zipを解凍した状態で置く）
3. Settings → Pages → Branch を `main`・`/(root)` に設定 → Save
4. 数分待って `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く
5. **スマホで開いて動くことを確認**

> 無料パートはここの「3」あたりで切る。**読者が実際に1個公開できてしまう**手前で有料に切り替えるのではなく、
> できれば **公開まで無料で体験させる**。信頼が最大化してレビューと紹介が回ります（→ `03`の無料パート設計）。

📸 アップロード画面／Pages設定画面／公開URLが出た瞬間／スマホ表示

## 第3章｜AIに作らせるプロンプトの型（2,500字・有料）

**5要素テンプレート：**

```
① 誰向け：〈例：Xのフォロワー向け、20代女性〉
② 遊びの中身：〈例：4つの質問に答えると性格タイプが12種類のどれかに分かれる〉
③ 技術条件：HTML/CSS/JavaScriptを1つのファイルにまとめて、index.html として完結させて
④ 見た目：スマホ縦画面前提、タップだけで操作、文字は大きめ、配色は〈  〉
⑤ 仕上げ：結果をコピーしてSNSに貼れるボタンを付けて。外部ライブラリは使わないで
```

- 良いプロンプト／悪いプロンプトの実例比較（同じ題材でBefore/After）
- **AIが長いコードを途中で切ったときの直し方**（「続きを出して」ではなく「index.htmlを全文で出し直して」）
- 出てきたコードの受け取り方（ファイル名・拡張子・文字コード）
- 修正の頼み方3パターン（見た目／文言／確率の調整）

## 第8章｜詰まったときの逆引き（1,500字・有料）

| 症状 | 原因 | 直し方 |
|---|---|---|
| URLを開くと404 | Pages未設定／ファイル名が違う／反映待ち | `index.html` が直下にあるか確認、数分待つ |
| 変更が反映されない | ブラウザキャッシュ／Actions待ち | スーパーリロード、数分待つ |
| スマホで崩れる | viewport指定なし | AIに「スマホ縦前提で作り直して」 |
| 文字化け | 文字コード | `<meta charset="utf-8">` の確認 |
| コードが途中で切れる | 出力上限 | 「index.htmlを全文で出し直して」 |
