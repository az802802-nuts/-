## X投稿テンプレ7本

**① ビフォーアフター型**
```
コードが1行も書けない僕が、
AIに指示しただけで作った診断アプリがこちら。

〈URL〉

かかった時間：〈◯〉分
かかったお金：0円
```

**② 実演型（動画/GIFを付ける）**
```
AIに「4問で性格が分かる診断を1ファイルで作って」と投げた結果。
これがそのまま自分のURLになります。〈動画〉
```

**③ 数字型**
```
一昨日公開した占いアプリ、〈◯〉人が遊んでくれました。
文字だけ投稿してた頃と反応が全然違う。
```

**④ 手順型（画像4枚）**
```
AIで作ったページを"自分のURL"で公開する手順、画像4枚で。
①AIに1ファイルで作らせる ②GitHubに置く ③Pagesをオンにする ④URLが出る
```

**⑤ 失敗型（共感を取る）**
```
最初、公開したのに404が出て3時間溶かしました。
原因は〈ファイル名がindex.htmlじゃなかった〉だけ。同じ罠にハマる人が多いはず。
```

**⑥ 応用型（サブペルソナに刺す）**
```
占い師さんに「無料診断ページ」を作って渡したら、
プロフィールのリンクに置いてもらえました。こういう需要、けっこうある。
```

**⑦ 募集型（制作代行の入口）**
```
練習も兼ねて、診断ページを無料で作ります（先着3名）。
「こういうの作りたい」をリプで教えてください。
```

## アフィリエイター向け素材（紹介を増やす仕込み）

Brainは紹介機能が売上のエンジンなので、**紹介する側の手間をゼロにする**のが効きます。
以下を1つのNotionページにまとめ、本文末と購入後メッセージで案内：

- 紹介用の訴求文（120字／短文／長文の3種）
- デモURL（そのまま貼れる）
- 使用可の画像素材（サムネ・スマホ画面）
- 「この人に刺さります」というターゲット説明
- 紹介料率の明記（40%）
