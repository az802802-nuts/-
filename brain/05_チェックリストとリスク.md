# 05｜公開前チェックリストとリスク管理

## A. 表現の安全性（景表法・特商法）— ここが一番事故る

| ❌ 書かない | ✅ 代わりにこう書く |
|---|---|
| 「誰でも月10万円稼げます」 | 「未経験の5人が、平均◯分で1本公開できました」 |
| 「必ず」「絶対」「不労所得」 | 「この手順どおりに進めれば公開まで到達できます」 |
| 「limited・残り3名」（実際は無制限） | 実際に制限するときだけ書く |
| 「通常10,000円→今だけ1,480円」（元値が架空） | **実際に販売した価格**だけを比較対象にする |

- 収益に触れるなら **「成果には個人差があり、収入を保証するものではありません」** を必ず併記
- モニターの声は **改変しない**。掲載許可を取ってから載せる
- 先行価格は **実際に値上げする**（やらないと二重価格表示になる）

## B. 著作権・ライセンス

- [ ] テンプレに使う画像・フォント・アイコンは商用利用・再配布が許可されたものか
- [ ] AIが出力したコードをそのまま特典として配る前に、実際に動かして確認したか
- [ ] 他人のBrain/note/ブログの文章を引用する場合は出典明記＋引用の範囲内か
- [ ] 星座占いの結果文言など、既存サービスからのコピーになっていないか

## C. 占い・診断コンテンツ特有の注意

- 娯楽・エンタメの範囲であることをページ内に明記（「この診断は娯楽目的です」）
- 健康・病気・寿命・金運などの **断定的な表現を避ける**（医療・投資の助言と受け取られない）
- 相手を傷つける結果文言（容姿・性格の否定）を入れない

## D. 各サービスの規約

- [ ] Brainの利用規約・出品ガイドライン（禁止ジャンル、返金、著作権、審査）を販売前に読む
- [ ] GitHub Pagesの利用規約（商用利用は可だが、帯域・用途の制限あり。ECサイト等の用途はNG）
- [ ] 生成AIサービスの出力物の利用条件（商用可・再配布可の範囲）
- [ ] 特典配布に使うNotion/Google Driveの共有設定が「リンクを知っている人だけ」になっているか

## E. 品質チェック（公開ボタンの前に）

- [ ] 別のスマホ（できれば他人の端末）で、記事内の全URLを開いた
- [ ] テンプレ5種すべてを**まっさらな状態から**手順どおりに公開して動いた
- [ ] スクショに個人情報（メールアドレス、実名、他人のアカウント）が写り込んでいない
- [ ] 無料パートだけを読んで「読者が1本公開できる」状態になっているか読み返した
- [ ] 誤字脱字（音読 or 読み上げで1周）
- [ ] 特典リンクが購入前の人に見えていないか
- [ ] サムネが縮小表示で読めるか

## F. 販売後の運用

- [ ] 購入者からの質問窓口の対応範囲を明記した（返信の目安時間、対応しない範囲）
- [ ] 内容が古くなったとき（サービスのUI変更）に追記する運用を決めた
- [ ] 低評価レビューが来たときの対応方針（感情的に返さない・内容を直して追記で応える）
- [ ] 売上の記録と確定申告の準備（副業なら年20万円超で申告が必要になる場合あり／要確認）

## G. 撤退・方針転換の基準

先に決めておくと消耗しません。

- 発売30日で **10本未満** → タイトル・サムネ・無料パートを1回だけ全面改稿して再告知
- それでも動かない → 案B（制作代行の受注ノウハウ）へ**内容を作り替える**のではなく、
  案Aの購入者に直接ヒアリングして「本当に欲しかったもの」を第2弾にする
