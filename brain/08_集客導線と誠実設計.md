# 08｜章立て v3：事実の確定と、集客導線の設計

## 0. 事実の確定（ここを間違えると商品が崩れる）

| 項目 | 事実 |
|---|---|
| 申請 | **必要**。必須のステップ |
| 今回、誰がやったか | **知人**。直也さんは申請していない |
| 直也さんの役割 | **講師**（資料作成と登壇） |
| 集客 | 市の広報誌に掲載。**最初の集客の工数がまるごと消えた** |
| 資料 | Claude ／ NotebookLM と**壁打ちして作った**（全自動生成ではない） |
| 流れ | 初回は無料講座 → 続きを希望する人は有料 |
| **直也さんの見解** | **申請は自分でやったほうがいい** |

> 前バージョンで「申請しなくても講師になれる」と書いたのは誤りでした。**申請は必要**です。
> 正しくは「申請は必要。そして**自分でやったほうがいい**」。これが商品の主張になります。

---

## 1. 商品の主張：「申請は自分でやれ」

今回は知人に任せた。それで講師には立てた。**でも、それを商品の推奨手順にはしない。**
理由を言語化すると、そのまま第1章の説得になります。

| # | 自分で申請すべき理由 |
|---|---|
| 1 | **行政の担当者と顔がつながる** — 次年度の相談が自分に来る |
| 2 | **締切・様式・NG事項を自分の手で知る** — 2回目以降が圧倒的に速い |
| 3 | **企画の主導権を握れる** — テーマ・対象・回数・日程を自分で決められる |
| 4 | **人に頼むと、その人がいなくなった瞬間に終わる** — 再現性がない |
| 5 | **近隣自治体へ横展開できない** — 自分で動けないと1つの市で止まる |

第1章の構成：
- 今回の実例（知人に任せた。おかげで登壇に集中できた）を**正直に開示する**
- そのうえで「なぜ2回目からは自分でやるべきか」を上の5点で説明する
- **初回だけ人に頼るのはアリ**。ただし「隣で見て、次は自分でやる」前提で頼むこと

この「自分は最初こうだった。だからあなたはこうしたほうがいい」という書き方は、
**盛らずに説得力が出る**、コンテンツで一番強い型です。

---

## 2. 申請パートを一次情報にする（＝販売前の唯一の宿題）

商品として「自分で申請しろ」と言う以上、**著者が自分で申請していないのは弱い。**
逆に言えば、ここさえ埋めれば商品は完成します。

### やること：次の1回を、自分で申請する

そのプロセスをそのまま記録すれば第2章になります。**実況として書けるので、むしろ生々しくて価値が高い。**

記録するもの：
- どこへ行ったか／電話したか（課の名前・窓口・担当者の役職）
- 何を聞かれたか、何を出したか（様式・分量・添付物）
- 締切はいつだったか（何ヶ月前）
- やりとりの回数と期間
- 直された点・断られた点
- **広報誌に載せる依頼はどの段階でしたか**

### 並行してやること：知人に取材する

自分で申請する前の**下準備**にもなり、章の裏取りにもなります。1〜2時間のヒアリングで足ります。
「知人に聞けば済むことを"知らないので書きません"で済ませる」のは、商品として弱い。

### リリース戦略（申請の締切は数ヶ月前のことが多いので）

| | やり方 | 向き不向き |
|---|---|---|
| 案1 | 申請が通ってから販売 | 一番きれいだが、**販売が数ヶ月先**になる |
| 案2 | 先にライト版（AI壁打ち編）を売り、申請章が揃ったら本編を出す | 収益が早い。二度手間 |
| **案3（推奨）** | **知人取材＋「自分の申請は進行中」を明記して先に出し、結果が出たら追記** | Brainは追記更新できる。**追記＝値上げの理由**になる |

案3なら、進行中であることを隠さずに書けます。
「私は今、2回目を自分で申請しています。その全記録はこの記事に追記します」＝**買う理由が増える**。

## 3. 広報誌の価値は「信用」ではなく「工数」

ここは言い方を間違えないこと。**読者に効くのは"集客をやらなくていい"という一点。**

自主開催なら、これを全部自分でやります：

```
告知文を書く → チラシを作る → 配る・貼る → SNSで拡散する
→ 申込フォームを作る → 問い合わせに答える → リマインドを送る
```

**広報誌に載ると、この工程がまるごと消えます。**（申込受付まで市側が担う場合もある）

副業・兼業で講師をやる人にとって、これは「信用がつく」より決定的です。
**集客をやらなくていい ＝ 続けられる。** ここを章のメッセージにします。

章に書くこと：
- 自主開催との**工数比較**（時間の実数で並べると効く）
- 載るために必要だったこと（＝申請とセットで動く。締切の逆算）
- 広報誌の限界も正直に（申込者の層が偏る／当日欠席がある／内容の書き換えが入る）

## 4. 資料は「AIが作る」ではなく「AIと壁打ちする」

ここは正確に書くこと。**誇張すると再現できない読者が出て、レビューで叩かれます。**

実際にやったのは、**Claude ／ NotebookLM と対話しながら資料を詰めた**こと。
価値は「ゼロから書かなくていい」「相談相手がいる状態で作れる」ことです。

### 壁打ちの型（第4章の中身）

| 段階 | 壁打ちで詰めること |
|---|---|
| 1 | 誰に何を教えるか（対象・レベル・ゴール）を言語化する |
| 2 | 90分の構成と順番。**何を削るか**を相談する |
| 3 | スライド・配布資料の文言（高齢者向けの言い換え） |
| 4 | 想定質問と、詰まりそうな操作の洗い出し |
| 5 | 抜け漏れチェック（「この講座で足りないものは？」と聞く） |
| 6 | **実機で全手順を通す** — AIの出力は必ずズレる。ここは人間の仕事 |

NotebookLM を使う場合は「参考資料・既存の手順書を読み込ませて、そこから講座用に組み直す」使い方を追記。

### 必ず入れる一文

> 「AIが全部作ってくれるわけではありません。決めるのは自分で、AIは壁打ち相手です。
> 　ただし、ゼロから書くのとは、かかる時間がまったく違います。」

**この正直さがそのままセールスの信頼性になり、返金リスクを下げます。**

## 6. セールスの核（訂正版）

> 「◯◯市の公民館で、市民向けホームページ講座の講師をしました。
> 　告知は市の広報誌。**集客の工数はゼロ**です。
> 　資料はAIとの壁打ちで作りました。初回は無料、続きを希望した方は有料講座へ。
> 　初回の申請は知人に任せましたが、**2回目は自分で出しています。その全記録も入れます。**」

この5行に、講師をやりたい人が知りたいことが全部入っています。しかも全部が事実です。
収益額を1円も語っていないので、景表法まわりのリスクもありません。
