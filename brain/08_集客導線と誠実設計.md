# 08｜集客導線（広報誌・無料→有料）と、知らないことの扱い方

## 結論

**触れます。むしろ主役に上げます。ただし「申請のやり方」としては絶対に書きません。**

理由は3つ。

1. **知らないことを書くのはBrainで一番やってはいけないこと**。返金・低評価・信用の喪失に直結する
2. そもそも申請手続きは自治体ごとに違うので、**"正解"を書くこと自体が不可能**。書けば必ず「うちの市では違った」が来る
3. **直也さんが実際に通ったルートのほうが、読者にとって価値が高い**。
   申請していないということは「**申請しなくても講師として入れた**」ということ。
   書類のハードルがゼロなぶん、企画書ルートより再現しやすく、しかも誰も書いていない

---

## 1. 持っているもの／持っていないものを分ける

| 手札 | 商品での扱い |
|---|---|
| ✅ 市の広報誌に載って告知された | **証拠**として見せる。手順としては書かない |
| ✅ 初回無料 → 次回以降は有料というステップが回った | **核心ノウハウ**。ここが一番売れる |
| ✅ 講座資料をAIで作った | 核心ノウハウ（第4章） |
| ✅ 自分は申請していない＝別ルートで講師になった | **これ自体がノウハウ**（→ 2） |
| ❌ 申請手続きの実務 | 書かない。「調べ方」に変換して渡す（→ 3） |

## 2. 第1章は「枠は"取る"より"乗る"ほうが早い」にする

読者にとって、役所に企画書を出すのは心理的ハードルが高い作業です。
**でも直也さんは出していない。それでも講師になっている。** ここが商品の独自性になります。

申請していないなら、実際に起きたことは次のどれかのはずです。**どれであっても商品になります。**

| ケース | 実際に起きたこと | 章タイトル |
|---|---|---|
| A | 市・公民館側が企画し、講師として依頼された | 「依頼される側になる」— 講師登録・実績の見せ方・最初の1回の作り方 |
| B | 所属する団体・会社・サークルが申請した | 「団体に乗る」— すでに枠を持っている組織の見つけ方 |
| C | 共催する事業者・仲間が申請した | 「共催という裏道」— 書類はパートナー、中身は自分 |
| D | 知人・紹介で話が来た | 「紹介で入る」— 誰に何と言っておくと声がかかるか |

→ **「自分で役所に申請しないで、講座の枠に入る4つの道」** としてまとめると、それ自体が独自ノウハウです。
企画書ルートより買い手のハードルが低いので、むしろ売れます。

自分で申請するルートは、**第2章に「もう一つの道」として置き、調べ方だけ渡す**。主役から降ろします。

## 3. 知らない部分の書き方（3つの型）

### 型①：最初に宣言する

> 「申請の手続きは自治体ごとに違います。この本では"正解の手順"ではなく、
> **"あなたの市の正解を30分で見つける手順"** を渡します。」

誠実であり、かつ事実です。しかもこの1文で「うちの市では違った」というクレームの芽が消えます。
**弱みの開示が、そのまま商品の信頼性になる**数少ないパターンです。

### 型②：質問リストに変換する

知らないことは「窓口に聞く質問リスト」にする。読者は電話1本で自分の市の正解を手に入れられます。

- 市民が講座を企画して持ち込む制度はありますか（名称は何ですか）
- 講師の登録制度はありますか
- 会場費の減免はありますか
- **広報誌に載せてもらえる条件と締切は何ですか**（何ヶ月前までですか）
- 講師謝金の規定はありますか
- 講座の中で、自分のサービスを案内してよい範囲はどこまでですか

### 型③：実例として見せる

「**私の場合はこうでした**」と限定して書き、一般化しない。
読者は"型"ではなく"実例"として受け取るので、齟齬が起きません。

## 4. 広報誌に1章使う（ここは触れないほうが損）

市の広報誌に載ったという事実は、**この商品でいちばん強い証拠**のひとつです。

- **全世帯に配布される**（回覧・折込・ポスティング）。しかも行政の信用が付いた状態で
- 民間で同等の露出を買えば相当な広告費。それが実質0円
- **高齢者層に届く数少ないメディア**（ネット広告では届かない層に届く）
- ただし載る条件・締切は自治体次第（数ヶ月前に決まることが多い）→ これは型②で渡す

**章タイトル案：「広報誌に載る、ということの意味」**
中身：何がすごいのか／実際どんな枠で載ったか（実例）／載せてもらうために確認すること（質問リスト）／載った後に何が起きたか（申込数・参加者層）

## 5. 【最重要】初回無料 → 有料ステップの設計

直也さんが実際に回している導線です。**買い手が一番知りたいのは、まさにここです。**
「タダで教えて、そこからどうやってお金にするの？」に答えられる人が、ほとんどいません。

### 型の名前

**フロントエンド（行政枠・無料・入門） → バックエンド（自主開催・有料・応用）**

この形が優れている理由：

1. **無料側の集客コストが0**（行政と広報誌がやってくれる）
2. **無料側で信用が完成する** — 90分も接触している。飛び込み営業には絶対にできない
3. **有料側に来るのは「もっと知りたい人」だけ** ＝ 説得がいらない
4. 行政の「入門→基礎→応用」というカリキュラム観と整合する ＝ 不自然さがない

### 書くべき中身

- 無料講座の**終わり方**（次があることをどう伝えるか。売り込みに聞こえない言い方）
- **案内の許可をどう取るか**（主催者への事前確認。ここを外すと二度と呼ばれない）
- **アンケートの設計**（「続きを希望する／しない」＝手を挙げた人にだけ届ける）
- 有料側の**価格・形式**（少人数／単発／連続／オンライン）
- **無料→有料の歩留まり**（実際の数字が出せると、商品の説得力が跳ね上がる）

### 必ず書く注意

- 行政主催の場での案内可否は**主催者の判断**。許可の範囲を超えない
- 個人情報は利用目的を明記して取得し、目的外に使わない
- **無料講座が「有料への釣り」に見えた瞬間に、信用も次年度の枠も失う。**
  無料単体で完結した価値を出しきること。ここが一番大事

## 6. 修正後の章立て（案E v2）

| 章 | タイトル | 出どころ |
|---|---|---|
| 0 | なぜ「行政の枠 × 無料講座」が最強の入口なのか | 実体験 |
| **1** | **枠は"取る"より"乗る" — 自分で申請しないで講師になる4つの道** | **実体験** |
| 2 | それでも自分で企画を出したい人へ（調べ方と質問リスト／正解は市ごとに違うと明言） | 調べ方として渡す |
| 3 | 広報誌に載る、ということの意味 | 実体験 |
| **4** | **【核心】AIで講座資料を1日で作る（プロンプト7本）** | **実体験** |
| 5 | 受講者が成果物を持ち帰る設計（ホームページ／1ファイルHTML） | 実体験 |
| 6 | 当日の運営90分の型 | 実体験 |
| **7** | **【核心】無料講座から有料ステップへ（フロント→バック導線）** | **実体験** |
| 8 | 2回目・横展開（実績報告書／近隣自治体／テーマ違い） | 実体験＋一般則 |
| 9 | 収益モデルと、権利・確定申告まわりの注意 | 一般則 |

**核心が第1章・第4章・第7章の3本になりました。しかも全部、直也さんが実際にやったことだけで構成されています。**
知らないこと（申請実務）は第2章に隔離し、「調べ方」として渡す。これで嘘をつかずに商品が成立します。

## 7. 追加で確認したいこと

| # | 質問 | これで決まること |
|---|---|---|
| 1 | **申請は誰がやったのか**（市側／所属団体／共催者／紹介者） | 第1章の中身そのもの |
| 2 | どういう経緯で講師になったのか（声がかかった／持ちかけた） | 第1章の再現手順 |
| 3 | 広報誌はどんな扱いだったか（何月号／大きさ／申込先） | 第3章 |
| 4 | **無料講座に何人来て、何人が有料へ進んだか** | 第7章＋セールスの数字 |
| 5 | 有料側の中身（価格・形式・回数） | 第7章 |
| 6 | 有料の案内は主催者に確認したか。どう伝えたか | 第7章の核心 |

**特に1と4。この2つが商品の背骨になります。**
